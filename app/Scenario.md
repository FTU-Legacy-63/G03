# Scenario

## OMO Game — Scenario Design & Decision Evaluation

The scenario framework used to develop the Open Market Operations (OMO) simulation is available here:

**[Scenario 8.0 — Excel Workbook](https://docs.google.com/spreadsheets/d/1F29oFFkw-PsIbhjPQ_tk1FUx7LPtVfPh/edit?rtpof=true&gid=1369538741#gid=1369538741))**

The workbook contains the economic context and auction decision scenarios for each game phase, phase-specific feedback evaluating players' decisions against economic conditions, overall game-flow evaluation, the standard flow, and auction and liquidity rules.

> The link above points to the Excel workbook in the same GitHub folder. Keep both files together when uploading to the repository.
